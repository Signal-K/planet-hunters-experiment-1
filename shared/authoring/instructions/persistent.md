# Persistent authoring instructions

- Keep the playfield visible; guidance is compact, dismissible and non-blocking.
- Do not show internal scene names in the game UI.
- Use the shared deep-dusk palette and shared HUD.
- Every visible or interactive thing is a named object in the scene tree.
- Scenes must work at phone portrait, phone landscape and desktop sizes.
- Free Ops is playable without accepting a contract.
- Web and native render the same authored structure and fixture state.
