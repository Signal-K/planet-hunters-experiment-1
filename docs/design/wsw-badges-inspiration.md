## What we took from them

- **One badge family per activity type** (GLOBE Observer protocols, Pokemon GO medal types) becomes one small badge per mission type.
- **Event-linked categories** (Pokemon GO Community Day focus, WSW "Rocket Revolution" launch theme) becomes: each mission type belongs to one existing sky event.
- **Tiers.** Pokemon GO and GLOBE tier by count. Our existing sky-event rule tiers by time (gold during the event, silver after). We keep the time rule so every badge in the Archive reads the same. Count tiers (bronze/silver/gold by classification count) are a possible follow-up and are NOT built.

| Mission type | Badge | Sky event / category |
| --- | --- | --- |

| Satellite / deep-space survey | Orbital Survey | New Moon Asteroid Hunt (dark-sky survey) |
| Citizen science (TESS, asteroid, Saturn) | Sky Observer | Saturn All Night |
| Construction / launch | Launch Builder | Rocket Revolution (launch) |

Tier: gold when completed 4-10 Oct 2026 (UTC), silver after, nothing before. Orionids (from 20 Oct) debris mining is untouched (PR #118).

## Art

The web badge row has no icon art and native uses the SF Symbol `rosette`. No new art was made. Each type reuses that row and gets a distinct colour token as a left edge: blue, sky/cyan, green, crimson, muted ink, ink.
