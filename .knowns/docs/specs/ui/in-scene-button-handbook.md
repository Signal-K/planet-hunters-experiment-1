# In-Scene Button Handbook

## Goal
Let players check what major buttons do without leaving the current screen.

## Scope
- Mission Debrief: explain sell/keep/scrap/salvage/leave/return actions.
- SideScroll Mining: explain mine, drone, inventory, return, and score/value context.

## UX Pattern
- Add a small `? Guide` button in each scene.
- Tapping toggles a compact overlay panel with plain-language button explanations.
- Tapping again closes the panel in-place.

## Constraints
- No scene navigation required.
- Overlay should not permanently block core gameplay controls.
