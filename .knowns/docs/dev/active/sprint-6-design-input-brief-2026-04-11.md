# Sprint 6 Design Input Brief — 2026-04-11

### 1. Launchpad spatial clarity pass

### 2. Debrief payout explanation
Task: `vmhqds`

### 3. Candidate detail / annotation panel

### 4. Scanner discovery framing and empty states
Task: `tp6eof`

### 5. Emergency loan modal
Task: `39hldq`
Goal: keep the mechanic important without making it feel punitive or like a hard blocker.

### 6. Optional panel empty states
Task: `zfthu2`

- MVP must be production-ready.
- Launchpad stays spatial/sandboxy.
- Debrief explanation should be minimal but trust-preserving.
- Control Station should simply exist as an optional click target once it is unlocked.
