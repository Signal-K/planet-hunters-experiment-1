# Spec: Shared Discovery Consensus
**Status:** Deferred (Long-term)
**Integration:** Star Sailors Ecosystem / Citizen Science

### Core Concept
A multi-layered verification system for TESS planet candidates.

### The Loop
1. **User A** discovers/classifies a candidate in "Planet Hunters."
2. **User B** sees this discovery on their Scanner as a "High-Value Target."
3. If **User B** confirms the classification, the "Consensus Level" increases.
4. At **High Consensus**, the discovery is flagged for transmission to actual astronomers.

### Rewards
- Both users receive a "Consensus Bonus" (XP/Francs).
- The original discoverer (User A) gets their name permanently attached to the node in the Shared World.

## Status Update — 2026-03-17

### Classification Notifications (Near-Term MVP)
- Being notified when your classification is **backed up or challenged** by another player is now a **near-term feature**, not fully deferred.
- This is the primary social retention hook: "I classified TIC-XXXX as not real, another user disagreed."
- Notification shows: which target, other user's classification, current consensus level.
- Players can see the consensus state for any target they have classified.

### Full Multiplayer Expansion (Deferred ~2026-04-07)
- Base interaction, docking, trading, and other multiplayer mechanics: deferred.
- Revisit and fully spec: ~2026-04-07.
