# Spec: Construction, Outposts & Refineries
**Status:** Deferred (Revisit in 1-4 weeks)
**Integration:** Star Sailors Ecosystem / Tiny Space Program / Crashlands

### Core Concept
Players can build static structures on discovered anomalies (Asteroids/Planets) to create a persistent presence and automate resource collection.

### Building Types
- **Settlements:** Increases "Scientific Reputation" and provides living quarters for characters.
- **Mining Outposts:** Passive resource collection (TSP-style) over time.
- **Refineries:** Converts raw ores (Iron, Silicates) into higher-value materials (Alloys) or Fuel.
- **Relay Stations:** Extends the range of the Scanner and allows "Fast Travel" (Refueling) in deep space.

### Mechanics (Crashlands/TSP Style)
- **Grid-based placement** in Godot.
- **Crafting:** Requires specific minerals mined from the "Active Mining" minigame.
- **Upgradable:** Each building can be leveled up to increase efficiency or capacity.

### Shared World
- Outposts built by players may become visible to others as "Neutral Trade Hubs" in the future.
