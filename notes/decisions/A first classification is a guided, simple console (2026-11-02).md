# A first classification is a guided, simple console (2026-11-02)

Liam, looking at the TESS classify console with the four-card help sheet open: "Too complex, too much going on in this screen. Need more of an interactive tutorial I think."

## Decision

- Until a player's first classification on an instrument (and through that first result), the console shows only the data well, a short readout and the answer steps. The optics plate, the project's data plate and the downlink terminal stay hidden. An "All controls" chip opens the full console at any time.
- The first visit plays the interactive coach, not the help sheet: one short line at a time beside the lit control, everything else dimmed. A step that asks the player to do something waits for them to do it and has no Next button. TESS: read the curve, drag a dip, drag the next dip, FOLD (folds at the gap between the player's own marks), then submit.
- The help sheet stays behind the `?` for reference, and its Show me replays the coach.
- Coach hints on a console are placed next to the control they name, never over the data well.
- Every classification console gets this, not only TESS (Liam answered "yes" for the asteroid and Saturn consoles, 2.11). The coach teaches the one tool that checks the answer (TESS: FOLD), with a plain key for it on the simple console.
