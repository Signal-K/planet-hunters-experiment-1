# Landnam notes

A ZenNotes vault for Landnam decisions and rules, kept in the game repo so every agent
session (local or cloud) reads the same rules Liam decided. Open this `notes/` folder as a
vault in ZenNotes. The older, wider workspace is `workspace/` in Signal-K/tickets-please;
its `projects/landnam/decisions` stay valid unless a note here replaces them.

- `decisions/` — one note per decision: what Liam decided, the date, and what it replaces.
- `cycles/` — the goals of each cycle as they became clear.

Rules for agents:

- Read `decisions/` before visual or mission work. A decision here wins over older docs.
- When Liam gives feedback that applies beyond the scene in front of you, write it here as
  a decision note in the same commit, and add the one-line rule to `docs/agents/product.md`.
- Mirror every new or changed note into Craft, folder **Landnam decisions**, so Liam can read
  it on iPad. The Markdown here is the source; Craft is the reading copy.
